Nuvora internal pages package

Copy the root HTML files into your Nuvora project root. Copy pages.css into css/. Copy the services/ folder into the project root. These pages reuse your existing css/style.css and js/script.js. The homepage index.html and existing style.css are intentionally not included/modified.

Pages: how-it-works, services, results, about, resources, contact, get-started, login, faq, privacy, terms, plus 5 service detail pages.
