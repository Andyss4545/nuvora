# Nuvora Frontend

Desktop-first Nuvora preventive-health product frontend built with plain HTML, CSS and JavaScript.

## Included
- Responsive desktop / laptop / tablet / mobile layouts
- Product-led Nuvora homepage UX
- Hero section and benefit panel
- Scroll-driven How It Works story
- Health dashboard with animated score and SVG trend chart
- Why Nuvora / stats section
- Services grid
- Member testimonial
- Final CTA and footer
- GSAP + ScrollTrigger motion
- Lenis CDN included for future smooth-scroll enhancement
- Reduced-motion support

## Run
Open `index.html` in a browser. For the smoothest local development experience, serve the folder with any static server.

## Replace placeholders
The image blocks are intentionally CSS placeholders so the structure works immediately. Replace them with approved Nuvora photography when assets are available.
